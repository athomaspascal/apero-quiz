# Quiz du Tableau Périodique des Éléments - Documentation Complète

## Date de création : 26 décembre 2025

---

## 📋 Vue d'ensemble

Un quiz complet couvrant **tous les 118 éléments** du tableau périodique de Mendeleïev avec 4 types de questions par élément :

1. **Numéro atomique** (position dans le tableau périodique)
2. **Nombre de neutrons** (isotope le plus stable)
3. **Année de découverte**
4. **Nom du découvreur**

## 🎯 Types de questions détaillés

### 1. Numéro atomique (118 questions)
**Exemple :**
```
Question : Quel est le numéro atomique de l'Hydrogène (H)?
Options : 1, 2, 3, 6
Réponse : 1
```

### 2. Nombre de neutrons (118 questions)
**Exemple :**
```
Question : Combien de neutrons l'isotope le plus stable de l'Hydrogène (H) possède-t-il généralement?
Options : 0, 2, 3, 4
Réponse : 0
```

### 3. Année de découverte (118 questions)
**Exemple :**
```
Question : En quelle année l'Hydrogène (H) a-t-il été découvert?
Options : 1766, 1776, 1756, 1786
Réponse : 1766
```

### 4. Découvreur (118 questions)
**Exemple :**
```
Question : Qui a découvert l'Hydrogène (H)?
Options : Henry Cavendish, Antoine Lavoisier, Dmitri Mendeleev, Marie Curie
Réponse : Henry Cavendish
```
