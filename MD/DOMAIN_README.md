# 🎯 Quiz App - Configuration Domaine "apero-quiz.com"

## Démarrage Rapide

### 1. Configuration Complète (Une seule fois)
```batch
setup-domain.bat
```

### 2. Démarrer l'Application
```batch
start_clean.bat
```

### 3. Accéder au Quiz
Ouvrir : **https://apero-quiz.com:8443**

---

## Scripts Disponibles

| Script | Description |
|--------|-------------|
| `setup-domain.bat` | Configure domaine + SSL + pare-feu |
| `setup-ssl.bat` | Configure SSL seulement |
| `start_clean.bat` | Démarre l'application |
| `configure-hosts-domain.bat` | Configure DNS local |
| `generate-ssl-cert-domain.bat` | Génère certificat pour domaine |
